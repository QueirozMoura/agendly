# Manrope — landing pública

Fonte variável Manrope, distribuição oficial do Google Fonts, sob SIL Open Font
License 1.1. O aviso de copyright e a licença integral estão em [OFL.txt](./OFL.txt).

- Origem do WOFF2: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
- Metadados: https://fonts.googleapis.com/css2?family=Manrope:wght@600..800&display=swap
- Origem da licença: https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt
- Obtidos em 21/10/2026, sem modificar o arquivo da fonte.

O subconjunto Latin inclui os caracteres usados nos títulos em português. Um único
WOFF2 (24.836 bytes) atende aos pesos 600–800 declarados no CSS. Caracteres fora do
subconjunto usam o fallback do sistema.

A família CSS `Agendly Landing Manrope` é usada somente nos títulos e na marca da
landing. `font-display: swap` mantém o texto visível durante o carregamento; o Vite
gera uma URL local com hash para cache. Não há CDN em tempo de execução nem preload
global, para não carregar a fonte em telas que não a utilizam.
