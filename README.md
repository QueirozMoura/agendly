# Agendly

Plataforma SaaS de agendamento e automação de atendimento para negócios.

## Objetivo

Simplificar a gestão de agendamentos, serviços, profissionais e comunicação
com clientes por meio do WhatsApp.

## Estrutura

- `frontend/`: aplicação web.
- `backend/`: API e regras de negócio.
- `docs/`: documentação técnica e planejamento.

## Configuração

Variáveis do backend (`NODE_ENV` obrigatório, `TRUST_PROXY`, produção): [`docs/CONFIGURATION.md`](docs/CONFIGURATION.md) e `.env.example`.
Desenvolvimento: `npm run dev -w backend`.
